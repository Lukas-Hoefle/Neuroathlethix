# Neuroathlethix – Business-Website

Meine eigene Website für mein Neuroathletik-Business, umgesetzt mit HTML, CSS und JavaScript.

🔗 **Live-Seite:** [https://lukas-hoefle.github.io/Neuroathlethix/](https://lukas-hoefle.github.io/Neuroathlethix/)

## Über das Projekt

Die Website stellt mein Angebot als Neuroathletik-Trainer vor und dient als zentrale Anlaufstelle für Interessierte – mit Informationen zum Angebot, Kontaktmöglichkeiten sowie den rechtlich erforderlichen Seiten (Impressum, Datenschutz).

## Verwendete Technologien

- HTML5
- CSS3
- JavaScript

## Seitenstruktur

- `index.html` – Startseite
- `kontakt.html` – Kontakt & Team
- `impressum.html` – Impressum
- `datenschutz.html` – Datenschutzerklärung
- `styles.css` – Zentrales Stylesheet
- `img/` – Bilder und Icons
